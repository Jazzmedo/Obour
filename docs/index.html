Your desktop

  1. Your apps live on another computer.

    A server in the closet, a workstation at the office, an old laptop. Obour brings their apps to the desktop you're sitting at.

  2. It connects over SSH.

    No remote desktop, no extra server: just the SSH login you already have.

  3. An app crosses over.

    It arrives as a normal window that moves, resizes and tiles like a local app. Wayland apps travel through waypipe, older X11 apps through SSH. Obour picks the right one for you.

  4. Its sound comes too.

    Audio plays on your speakers, over the same connection.

  5. Files cross both ways.

    Drag a file into a remote app, or copy it there and paste it here.

  6. And it wears your theme.

    Your colors, icons, fonts and cursor, in GTK, Qt and KDE apps alike.

Connecting

  • Host setupFinds missing tools on the other computer and installs them when you agree.
  • Easy loginsYour SSH key first; after one password it can set up key login for you.
  • TailscaleA second address per computer, for when the usual one can't be reached.
  • Smart fallbacksIf a Wayland app fails, Obour retries without GPU sharing, then with X11.

Day to day

  • App browserSee a computer's installed apps with their icons, add them in one click.
  • Your app menuPut any remote app in your system's app menu.
  • Closes cleanlyClose the window and what the app left running on the host ends too.
  • Backup and restoreEverything in one .zip, ready for a new computer.

Get Obour.

Download the file for your system from the latest release, then run its command. The other computer only needs an SSH server; Obour offers to install the rest.

Latest release
AppImage, any distribution (open it with Gear Lever for updates)
chmod +x Obour-*-x86_64.AppImage && ./Obour-*-x86_64.AppImage
Debian / Ubuntu
sudo apt install ./obour_*_all.deb
Fedora / openSUSE
sudo dnf install ./obour-*.noarch.rpm
Nix
nix run github:Jazzmedo/Obour
